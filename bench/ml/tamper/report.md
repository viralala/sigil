# Sigil tamper model: honest evaluation (synthetic tampering)

Date: 2026-11-04. Model: `tamper-gb-2026-11-04-2e3c72ba` (gb). Generated by `eval.py`; numbers below are produced by that script, not typed by hand.

## Verdict: WEAK

AUC on all test data 0.529, on unseen templates 0.533, on whole held-out families 0.529, on real CESAC certificates only 0.587. This is a hint generator that sits under the Witness Model (machine checks are never stronger than 'checked'); it is not a detector anyone should rely on alone.

## What was measured, and what it does NOT prove

- Every tampered image here was made by **our own synthetic generator** (`gen_dataset.py`): text replaced (font-matched and mismatched), splice from another certificate, copy-move, seal/signature pasted, edit then re-save at another JPEG quality. Real forgers use other tools and tricks. A good score here does not mean the model catches real forgeries.
- Genuine certificates are either our own fictional templates (invented names, 6 families) or real CESAC certificates. Real genuine certificates only appear as genuine (and as the base of synthetic edits); **there is no real forgery in this evaluation at all.**
- Genuine and tampered images share the same degradation sampler (PNG, JPEG once/twice, screenshot, re-photo, blur, rotation, glare), so 'looks degraded' is not a cue. The tables below check this directly.
- The real CESAC set is small (one participation template used in training, one winner family and one organiser family held out). Those confidence intervals are wide.
- Features are statistical (error level analysis, noise, sharpness, JPEG block grid, colour, repeated blocks). A forger who edits then screenshots, prints and re-photographs removes most of this evidence. A perfect background fill plus a matching font leaves very little for any pixel statistic to find.
- Thresholds were chosen on the validation split only (about 5% of genuine pages flagged 'some signs', about 1% 'strong signs'); no test data was used to tune anything.

## Reproduce

```
python gen_dataset.py        # renders + tampers into the private folder (needs the CESAC originals, kept outside the repo)
node extract_features.mjs    # same feature code that serves production (packages/forensics)
python train.py              # compare logistic regression / gradient boosting / small MLP on train+val, calibrate, export JSON
python eval.py               # this report
```
Private data (real renders, feature tables with ids) stays in `sigil-private/ml-tamper/` outside the repo. Seeds are fixed in the scripts; `train_log.json` has the validation comparison of all candidates.
